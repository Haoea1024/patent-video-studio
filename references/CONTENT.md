# 专利内容与选题

## 目的和受众

视频服务成果转化：让可能采购、联合开发、许可或受让技术的企业负责人、研发负责人和产品负责人快速判断“解决什么问题、如何实现、与我有何关系、怎样进一步了解”。不是向专家完整复述权利要求，也不是面向公众保证产品疗效或投资收益。

默认语气：专业、清楚、克制。痛点具体，少用“颠覆、全球领先、革命性、零成本、百分百”等无依据词。不把“手册五星级”改写为官方质量认证。

## 事实卡（写文案之前完成）

每项内容要能回到一条原文：

| 项目 | 填写方法 |
|---|---|
| 项目名、号码 | 区分申请号与授权公告号，保留来源实际写法 |
| 权利人/团队 | 核对主体；发明人所属学校不等于专利权必然归学校 |
| 解决的问题 | 具体对象、工况和现有困难，不泛化成全行业结论 |
| 技术机制 | 用 2–4 步解释输入、结构/处理、输出，保留成立条件 |
| 差异与价值 | 分清专利自述效果、实测数据、推测应用方向 |
| 成熟度 | 原文有什么写什么；未知写待核实 |
| 合作和联系 | 仅用资料或用户给出的公开对接方式，未知则不显示电话邮箱 |
| 数据与限制 | 单位、测试条件、样本范围一起记录；讲不清条件宁可不放数值 |

配置的 sources 是文件/网址及位置；facts 是证据支持的独立主张；scenes.evidence_ids 是这段话依赖哪些事实。引用结构校验通过不代表源文件已被阅读。

手册排版可能把相邻项目介绍串页或复制错。标题、申请号、原理、发明人不一致时回专利原文查证；不能把另一个项目的成熟度、实验结论挪过来。网页背景只能补充行业语境，不能借别家公司的数据证明本专利性能。

## 六镜头写法

1. 钩子（约 5–7 秒）：一句具体问题，如“芯片发热不均，散热能否自动调整？”画面马上出现研究对象。
2. 方案（约 7–10 秒）：这是谁的技术，核心放了什么结构/材料/模型。
3. 原理（约 8–12 秒）：用动作或信号展示因果关系。
4. 特点（约 7–11 秒）：只讲一项有根据的差异或下一步机制。
5. 企业价值（约 9–12 秒）：点出适合什么企业，同时明确成熟度。
6. 洽谈（约 7–10 秒）：简短邀请，停留联系人信息。不念专利号，不凭空编联系人。

通常 180–260 个汉字，句子短但不要切成逐字播报。每个字幕短句最好 8–20 字，最长 36 字；用自然标点断句。合成后太长先改稿，不强行把语速调得很快。

机构身份从首帧显示，不需要开头再念一大段机构全称。技术名过长可在标题中合理简写，完整名称留在项目配置和最后一镜。

## 不同领域如何选镜头

- 传感/检测：对象 → 传感信号 → 模型/判断 → 应用。没有临床/工业验证就不展示已上线仪表数据。
- 热管理/机械：结构 → 工况变化 → 结构响应 → 目标效果。结构形变方向必须核实。
- 分离/材料：加工结构 → 表面特性 → 选择性通过/截留 → 应用方向。先明确哪一相通过，不能靠画面好看来猜。
- 软件/算法：输入 → 处理 → 输出，用 flow/compare；没有对照实验就不画精度提升百分比。
- 化学/生物：对象与过程用示意图或可靠图片；不把体外结果写成临床疗效，不把潜在用途写成已获准应用。
- 外观设计：用合法来源产品图和 image 镜头；不要声称获得发明专利。

## 三个样片的经验，不是可复制到任何专利的事实

油黏度样片贡献了“痛点—信号—求解—企业价值”的叙事和传感动画。芯片样片贡献了局部温度和弹簧响应。铜网样片贡献了分离方向与加工示意。这些视觉语言可复用，物理机制不能随意套用。

原始油黏度样片的字幕曾按比例估时；本包统一升级为真实音频时间戳。原始样片中的较强推广表述不构成以后可随便沿用的依据。本包油黏度示例已改为更保守的可追溯表达。三个 `examples/*.json` 是通用引擎适配示例，并非逐像素复刻旧视频。
