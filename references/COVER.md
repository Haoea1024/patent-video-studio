# 独立封面

目标是让潜在企业用户愿意点开。不是把整页专利浓缩成海报。图片不在播放内容中展示；MP4 attached_pic 只供支持的播放器/平台读取，发布平台不支持时手动上传 cover.png。

## 默认执行，不等用户再提封面

生成视频即包含制作与交付封面。Agent负责从当前资料理解目标企业、应用痛点与可证实价值，不能把这些判断全留给用户。按下面顺序执行：

1. 用户已经指定封面：检查并沿用，填写 `cover.image`，只做必要的尺寸适配。
2. 未指定：先为当前专利写2–3个短标题候选，自行选择最清晰且有依据的一个；每行建议4–10字、最多13字。优先“应用对象＋动作/价值＋具体悬念”，不使用虚构效率、夸大疗效或泛泛的“黑科技震撼来袭”。完整专利长名称可留在正文结尾。
3. 选一个与本专利相符的主视觉，如网面上的油水选择性透过、局部响应结构、磁共振设备与重建数据。不把另一个专利的设备图换标题复用。
4. 实际环境中有可用绘图工具时，优先调用它生成符合构图的图片。使用当前工具的真实接口，不照抄Codex工具名、不假称已生成；保存图片、提示词和服务名称。生成失败最多修正两次，之后直接使用内置封面。
5. 没有绘图工具、没有密钥或工具失败时，**直接完成内置图解排版封面**，不要停止、要求用户另找图片、只输出提示词或跳过封面。采用本项目机制镜头作主视觉，仍需精心选择标题及代表状态。

```powershell
python "技能目录/scripts/pipeline.py" cover "项目目录/project.json" --out "项目目录/build"
```

命令不需要先运行audio，也不调用TTS或图像服务。已有配音时间轴不会被覆盖。`preview/render/build`调用同一封面生成逻辑。结果必须含：

- `cover.png`：1080×1920独立封面。
- `cover-thumbnail.jpg`：270×480手机缩略图，检查是否一眼看懂。
- `cover-brief.json`：当前专利、受众、标题、主视觉、事实引用与实际模式。
- `cover-prompt.txt`：从当前配置生成的绘图提示词，可供真实绘图工具调用；它本身不是图片。
- `cover-check.json`：尺寸、非空图像、配置和文件哈希检查；**不证明内容准确或有吸引力**。

主视觉默认取与 `cover.visual` 匹配的镜头，可用 `cover.scene_id` 精确选择，`cover.time` 选择该镜头内代表时刻（秒）。不要选入场前空白帧。比如铜网选择油滴正在透过的状态，MRI选择设备外观或数据重建过程。图片字段缺省即可自动生成图解封面；有图片时填写相对项目的路径，不引用技能示例封面作为新项目成品。

```json
"cover": {
  "headline": ["一张铜网", "让油通过", "把水留住？"],
  "visual": "separation",
  "scene_id": "principle",
  "time": 3.2
}
```

上例仅说明配置语法，不是其他专利的默认文案。

## 已认可构图

1. 顶部明确机构与专利类型，不能伪造校徽。
2. 上半部分 2–3 行大字，具体问题或价值，暖白/琥珀配色；手机缩略图仍能读。
3. 下半部分一个清晰技术主视觉：有空间层次的结构、材料或过程示意，不堆小图。
4. 小标签写真实成熟度；底部“寻找合作企业 · 欢迎洽谈”。
5. 深蓝底、宋体标题、铜金/琥珀强调、青色辅助，与正文一致。

查看 examples 中三张 approved-cover.png。它们只供风格参考，不得给新项目复制原来的项目内容。默认文字排版封面由 renderer 自动出图；生成式封面须使用当前真正可用的图像工具。

## 给图像工具的提示词模板

替换方括号全部内容后提交，不要把方括号占位符原样发给工具：

> 制作一张 9:16 中文专利成果转化短视频封面，1080×1920 构图。深午夜蓝背景、暖白粗宋体大字、琥珀金重点、青色辅助，专业、清爽、精致的科学三维示意风格。顶部标识准确写“[机构 · 类型]”。主标题三行分别为“[问题/对象]”“[动作/价值]”“[短问句]”，要在手机上醒目。下方主视觉：[依据专利核实的具体结构与动作，明确方向和不能误画的关系]。写明“原理示意”。成熟度准确写“[原文阶段]”。底栏“寻找合作企业 · 欢迎洽谈”。只包含要求的文字，不添加数字、认证、专利号、额外口号或联系方式。保留边缘安全距离。

有参考图时说明仅参考风格/结构哪一部分；不要让绘图模型根据标题自行发明机械结构。实际图片生成失败两次仍无法修正时使用排版封面并如实说明，不把乱码封面交给用户。

## 检查

- 中文逐字正确，号码没有误写，机构身份无误。
- 物理方向正确：铜网样例是油穿过、水在上方；芯片样例是局部弹簧收缩，不能画成整段凭空缩短。
- 颜色是解释工具，不暗示真实温度/实验结果。
- 没有未经证实的降温率、净化率、病症疗效、产品认证。
- 没有把封面塞进第一帧；首帧仍是正文动画与机构标识。
- 外部图片填写 cover.image；程序按比例补边，不拉伸。
- 打开270×480缩略图：机构标识、主标题、核心对象能否辨认？小字堆满、主体太小或标题太长就修正，不缩到勉强塞下。
- 新旧项目是否还有相同的技术文字、设备或成熟度？相同必须有当前资料依据，不能只是忘了替换。
- 原图与缩略图审阅通过后，最终回复单独给出封面文件链接/附件和视频链接；不要仅把图片嵌入MP4后就当作已交付。

新图存入当前项目目录，保留使用的最终提示词及生成工具名称，方便重做。图像工具不可用时不要求用户必须购买服务。
