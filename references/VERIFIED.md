# 验证记录

验证日期：2026-11-17。环境：Windows、Python 3.14.7；实际库版本见 requirements-tested.txt。

## v0.2 动画修正

- 根据用户反馈修复“换专利后只生成文字流程卡”的路径：配置要求至少两镜机制演示，正文时长占比至少35%；为不匹配内置模板的专利提供custom接口。
- 新增MRI模板的采集、训练数据生成、迭代、重建、应用五种模式，立体设备、柔和光影与带拖尾数据流；不依赖外部绘图服务。
- 18项测试在本机通过，包含四个示例的实际浏览器主体运动检测、custom动画加载、冻结主体负例。CI新增浏览器检查任务。
- 磁共振精修样片完整导出：61秒、1464帧、1080×1920，附加独立封面；综合响度-16.90 LUFS，真峰值-3.52 dBFS，配乐中位电平低于人声21.04 dB。
- 核心演示占非CTA正文58%，三个机制镜头的前中后三帧均有主体状态变化，已目视核对；新增motion-storyboard与motion-check交付。
- 合成体模只作技术原理说明，未运行专利训练网络、未使用临床影像、不证明真实重建性能。未在WorkBuddy或指定国产模型中独立运行新版，安装后的模型执行效果仍需实际测试。

## v0.1 原始验证

已执行并通过：

- 技能 frontmatter/结构检查。
- 11 项合同测试：三个示例、错误出处、未知镜头、错误模式、专利号禁读、真实词时间戳匹配、错字/错序拦截、旧配置缓存拦截、素材相对路径、结尾名称一致性。
- 原手册 321 页文本提取；指定第 28 页渲染并与已有页面核对。
- 铜网示例默认 Edge TTS 端到端成片：54 秒、1080×1920、1296 帧、H.264/AAC、附加封面；词级字幕。
- 芯片示例通过外部音频清单导入真实音频/词时间戳，生成音轨与全部镜头预览。
- 滑油示例默认配音与全部镜头预览。
- ZIP 解压到新的中文路径，再用外部音频/真实句级时间戳完整生成 54 秒视频。独立相对资源路径可用，句级模式不假造逐词同步。
- 自定义图片镜头和外部封面加载、五节点流程图、五卡片边界布局预览。
- 查看生成的分镜、封面、首尾帧，修复封面非等比缩放和长名称不自然断行。
- 最终迁移测试视频：综合响度 -16.90 LUFS，真峰值 -3.63 dBFS，人声有效区间音乐中位电平低 21.32 dB；完整解码通过。

未验证/不应夸大：

- 未在 WorkBuddy 客户端实际导入；安装入口依据官方文档核对。
- 未用任何指定国产大模型独立跑完任务；不能保证其事实理解与执行稳定性。
- 未实际调用国产 TTS API；已验证的是可供其接入的外部音频数据契约。
- 未在 macOS/Linux 或完全干净的新机器安装运行。
- 本次没有模型音频理解/人工试听结论；已执行自动响度/峰值检查。使用者仍应检查术语发音与节奏。
- 脚本与模板不等于任意专利都可自动生成专用三维动画；原理不同需选择适用机制或实现custom动画，图片不能替代演示。

本文件仅记录制作时的验证结果；后续修改代码、模型、语音服务、依赖版本或操作系统后，应重跑相关检查。
